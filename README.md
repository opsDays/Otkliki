# Отклики / Otkliki

Портативное приложение Days для учёта откликов на вакансии. Интерфейс на русском и английском.

**Исходный код находится в папке [`app`](app).** Он открыт для просмотра;
собственный код проекта опубликован под [MIT-лицензией](LICENSE).
У сторонних компонентов и изображений [отдельные условия](THIRD_PARTY_NOTICES.md).

## Скачать готовое приложение

[Открыть последнюю опубликованную версию](https://github.com/opsDays/Otkliki/releases/latest).
В разделе Assets выберите ZIP для своей системы и распакуйте его целиком.

## Что умеет приложение

Записи о вакансиях, статусы, заметки, профиль, CV, шаблоны писем, вложения,
импорт таблиц и текста, экспорт в Excel, календарь, напоминания, статистика,
резервные копии, темы и компактный вид таблицы. Инструкция по кнопкам есть в меню «Справка».

## Запуск из исходников

Нужны Node.js 22 или новее и npm. Скачайте репозиторий кнопкой Code → Download ZIP,
распакуйте и откройте терминал в папке, где находится `package.json`.

```sh
npm install
npm run verify:source
npm start
```

Первая команда загружает Electron 44.7.0 и его зависимости из интернета.
При таком запуске личные данные сохраняются в `.local-profile/data` внутри
папки проекта. Эта папка исключена из Git. Для штатного выхода используйте меню приложения.

## Собрать портативную папку для Windows

На Windows после `npm install` выполните:

```sh
npm run build:win
```

Результат: `dist/Otkliki-Portable-1.4/Otkliki.exe`. Переносить нужно всю папку,
не один EXE. Новая сборка начинается с пустой папки `data`.
Повторная сборка не перезаписывает существующий результат, чтобы не затронуть данные.

Это локальная сборка без подписи. У EXE остаётся стандартная системная иконка
Electron; иконка внутри приложения берётся из исходников. Она не обязана побайтно
совпадать с готовым релизом. Для macOS здесь предусмотрен запуск через `npm start`;
команда `build:win` предназначена только для Windows.

## Где смотреть код

- `app/main.cjs`, `app/preload.cjs`: окно, меню и взаимодействие с системой.
- `app/store.cjs`, `app/feature-store.cjs`: хранение, CV, импорт и резервные копии.
- `app/index.html`, `app/applications.js`: интерфейс и список откликов.
- `app/import-*.js`: импорт таблиц и текста.
- `app/feature-main.cjs`, `app/plus.js`, `app/workflow.js`: дополнительные функции.
- `scripts/`: запуск, сборка и проверка файлов исходников.

## Проверка и личные данные

В исходниках список записей и профиль изначально пусты; CV, резервные копии
и файлы пользовательского хранилища сюда не включены. Готовая портативная версия
хранит данные в папке `data` рядом с приложением. Не загружайте эту папку на GitHub.

`SOURCE_SHA256.json` содержит хеши исходного снимка версии 1.4.
`npm run verify:source` проверяет его целостность, а не безопасность программы.
При подготовке этой публикации файлы `app/` сверены с файлами приложения
в локальном архиве Windows 1.4. Проверка не является независимым аудитом безопасности.
